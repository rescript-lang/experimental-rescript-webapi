## System fonts

The documentation site uses system sans-serif and monospace font stacks. It does not
redistribute font binaries. The rendered typography may vary with fonts installed by the reader's
operating system.

The previous bundled Inter and Roboto Mono WOFF2 files were removed because the repository
did not record their source releases, subset-generation process, or applicable license notices.
Font metadata in those binaries identified family and version numbers but did not establish
source provenance or licensing. Rather than infer a license from a family name or an upstream
project's current terms, the site now relies on fonts already available on the reader's system.

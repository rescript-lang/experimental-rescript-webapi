The [Web APIs](https://developer.mozilla.org/en-US/docs/Web/API) are vast and ever-growing. We need your help to make them better.  
There is no way our [contributors](https://github.com/rescript-lang/experimental-rescript-webapi/graphs/contributors) can cover everything.  
And that's where you come in! A small PR, focused on what you want to get out of this project can make a huge difference.

## Recommended workflow

We recommend the following overall workflow when developing for this repository:

- Fork this repository
- Always work in your fork
- Always keep your fork up to date

Add the upstream repository once, if it is not already configured:

```shell
git remote add upstream https://github.com/rescript-lang/experimental-rescript-webapi.git
```

Check `git remote -v` first to avoid adding the same remote twice.

### Updating your fork

Update `main` without deleting local files or untracked work:

```shell
git checkout main
git fetch upstream
git merge --ff-only upstream/main
git push
```

The fast-forward-only merge stops rather than rewriting history if your fork's `main` has
diverged. Keep work on feature branches; commit or stash changes before switching branches.
This updates your local `main` from upstream and pushes it to your fork's configured `origin`.

## Initial build

Install the dependencies and compile the bindings using `ReScript`:

```shell
npm install && npm run build
```
